# Nada Mohamed’s portfolio

A personal engineering portfolio for employers, collaborators, and readers evaluating Nada’s AI/ML, backend, and applied systems work. The site should help readers inspect concrete projects and responsibilities, verify achievements, access the CV, and make contact.

React, Vite, TypeScript, and CSS Modules remain the stack. Typed data under `src/data` owns content. GitHub Pages deploys from `main`; the archive uses `#/projects` because there is no server-side route fallback. Microsoft Clarity and existing outbound event names are preserved.

This surface is an experience of the engineer’s work, with factual readable case studies. Violet is part of its identity. Avoid startup landing-page effects, generic marketing copy, new credentials, or a replacement trend aesthetic. See DESIGN.md for the implemented visual and interaction system.
